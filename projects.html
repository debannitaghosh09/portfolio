PawsAdopt — Pet Adoption Website

A responsive pet adoption website designed to connect pet lovers with their perfect companion. The site emphasizes clean UI/UX principles and delivers a seamless experience across all devices.

Built with vanilla HTML, CSS, and JavaScript, this project demonstrates skills in responsive design, user interface development, and creating engaging web experiences. The site is fully mobile-friendly and focuses on accessibility and performance.
